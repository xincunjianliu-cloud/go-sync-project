# タイルセットの運用ルール

## 1. 置き場所
| もの | 置き場所 |
|---|---|
| タイルセット画像(PNG) | `assets/images/tiles/` |
| タイルセット(Tiledの`.tsx`) | `assets/tilesets/` |
| マップ(`.tmj`) | `assets/maps/` |

- タイルセットは**テーマごとに分ける**(学校＝`school`、水＝`water`など)
- 1枚のマップで複数のタイルセットを使ってよい
- マップには**外部タイルセット(`.tsx`)だけを使う**。マップに埋め込んだタイルセットはテストで止まる

## 2. 新しいタイルセットを足すとき
1. PNGを**先に** `assets/images/tiles/` へコピーする(ダウンロードフォルダから直接選ばない)
2. Tiledで「新しいタイルセット」→ 画像に1.のPNGを選び、`assets/tilesets/` に `.tsx` で保存する
3. マップの「タイルセット」パネルで「外部タイルセットを追加」から2.の`.tsx`を選ぶ

## 3. 既存のタイルセット画像を描き足すとき
- **同じファイル名のまま上書き保存**する(`school (2).png` のような別名にしない)
- **横幅は変えない**。足すときは**下に行を追加**する
  - 横幅が変わるとタイル番号がずれて、全マップの見た目が崩れる
- 描き足したらTiledでその`.tsx`を開いて保存し直す(画像の大きさが`.tsx`に記録される)

## 4. 当たり判定
- `kabe` レイヤーに置いたタイルは通れない(従来どおり)
- タイルセットエディタでタイルにカスタムプロパティ **`wall`(bool) = true** を付けると、
  そのタイルは**どのレイヤーに置いても**通れない(例: 水のタイル)

## 5. チェック
`go test ./...` で次を確かめる。GitHubに上げたときもCIで同じテストが走り、失敗したら公開されない。
- マップのタイルセットがすべて `assets/tilesets/` の外部タイルセットか
- 画像が `assets/images/` の中にあり、大きさが `.tsx` の記述と一致しているか
- マップに置いたタイル番号が、どれかのタイルセットに含まれているか
