# スプレッドシートでシナリオを書くときのルール

## 1. 基本の流れ
1. スプレッドシートに**1タブ＝1ファイル**で書く(opening, chapter1〜4, boss_1〜4)
2. 書き終わったら以下を実行してゲーム用データを作り直す
   ```bash
   go run ./tools/dialoguegen
   ```
3. 生成されたJSON(`assets/dialogues/…`)は直接いじらない。**直すのは必ずスプレッドシート側**

## 2. 1行目は見出し
1行目に次の見出しを書く(列の順番は自由)

| 見出し | 内容 | 書き方 |
|---|---|---|
| `id` | 会話のID | **全行に書く**(ボスタブは不要) |
| `phase` | いつ流れる会話か | **全行に書く** |
| `speaker` | 話す人 | **全行に書く**(空欄＝ナレーション) |
| `expression` | 表情 | 通常以外なら**毎行書く** |
| `text` | セリフ | 1行＝1ページ |
| `bgm` | 会話中の曲 | 会話の**最初の行に1回** |
| `side` | 立ち絵の左右 | 話者ごとに**最初の発言行に1回**(省略可＝自動配置) |
| `background` | 背景画像 | 会話の**最初の行に1回** |

## 3. 各列の書き方

### id
- 同じ会話の行には全部同じidを書く。空欄はエラー
- **全タブを通して重複禁止**
- Tiledのイベントの `text` に `event_story_<id>` と書いて呼び出す

### phase
- 通常タブ：`first`(1回目) / `repeat`(2回目以降)。空欄は `first` 扱い
- ボスタブ：`battle`(戦闘前) / `clear`(撃破後)。空欄はエラー
- `repeat` は全行に書かないと、その行が1回目の会話に混ざる

### speaker
- 空欄 → ナレーション
- `player1`〜`4` → ブロリー / パラガス / ベジータ / トランクスルー
- `boss1`〜`4` → ボス1〜4
- それ以外 → 書いた文字がそのままNPC名(例:`村長`)

### expression
- `0`=通常 `1`=笑顔 `2`=怒り `3`=驚き
- 前の行を引き継がない。空欄は通常(0)に戻る

### text
- **セル内改行(Ctrl+Enter)がそのまま画面の改行**になる
- **1ページ最大3行**。4行目以降は表示されない
- 自動で折り返さないので、長い行は自分で改行する
- 次のページにしたいときは行を分ける
- `|` によるページ区切りはTiledに直書きしたセリフ専用。スプレッドシートでは使えない

### bgm
`talk_peaceful`(穏やか) / `talk_tense`(緊迫) / `talk_scary`(不穏) / `talk_sad`(悲しい) / `field1`〜`4` / `battle_normal` / `battle_boss` / `battle_lastboss` / `title` / `ending`

### side
- `0`=左、`1`=右
- speaker が空欄の行に書くとエラー

### background
- `assets/images/backgrounds/<キー>.png` のキーを書くと、マップの代わりに全画面表示される
- 空欄ならマップをそのまま表示

## 4. 記入例

| id | phase | speaker | expression | text | bgm | side |
|---|---|---|---|---|---|---|
| chief | first | 村長 | 0 | よく来てくれた。⏎この村は今、大変なんだ。 | talk_peaceful | 1 |
| chief | first | player1 | 3 | 何があった？ | | 0 |
| chief | first | 村長 | 2 | 魔物が現れたのだ！ | | |
| chief | first | | | 村長は重い口を開いた。 | | |
| chief | repeat | 村長 | 0 | 頼んだぞ。 | | |

(⏎＝セル内改行)

Tiled側：村長オブジェクトの `text` に `event_story_chief` と書く。
`repeat` の行が無い場合は、2回目以降も `first` の会話が流れる。

## 5. ボスタブ(boss_1〜4)
- タブ名は `boss_1`〜`boss_4` にする。**id列は不要**
- phase は `battle` か `clear` を全行に書く
- Tiled側はイベントの `bossid` に 1〜4 を設定する

## 6. その他
- 空行は区切りとして使ってOK(無視される)
- ゲーム中に「……」しか出ない → Tiled側のidの打ち間違いを疑う
- タブを増やしたら `tools/dialoguegen/config.json` にタブ名と gid(URLの `gid=` の後ろの数字)を追加。ボスタブは `"kind": "boss"` も付ける
- スプレッドシートは「リンクを知っている全員が閲覧可」で共有しておく
- id・phase は範囲選択して **Ctrl+D** で下にコピーすると楽
