# 作業の手順

## やり取り(GitHub Desktop)

**作業を始めるとき**
1. Tiledを閉じる(開いたままだと、ほかのPCの変更を消してしまうことがある)
2. GitHub Desktop の「**Fetch origin**」を押す
3. ボタンが「**Pull origin**」に変わったら、それも押す(ほかのPCの変更が入る)

**作業が終わったとき**
1. GitHub Desktop の左下の欄に、何をしたか一言書く(例:「学校のマップを直した」)
2. 「**Commit to main**」を押す
3. 「**Push origin**」を押す(ほかのPCに届く。Web版も自動で公開される)

**こんなときは**
- 最初から「Pull origin」が出ていたら、Fetch は飛ばしてよい
- Push で「先に Pull して」と言われたら、**Pull origin → もう一度 Push origin**
- Tiled に「ファイルが変更されました」と出たら、「**再読み込み**」を選ぶ
- **同じマップを2台以上で同時に直さない**

## シナリオ・ステータスを直したとき、戦闘背景の画像を足したとき、最初のマップを変えたとき

```
go run ./tools/update
```

会話と強さの取り込み、Tiledの一覧(会話・敵・戦闘背景)の作り直し、ゲームの最初のマップ(マップ設定でチェックしたマップ)の反映を全部まとめてやる。終わったらTiledを開き直し、Commit → Push。

## 新しいマップを作るとき

```
go run ./tools/newmap 名前
```

`assets\maps\名前.tmj` ができる(名前は英小文字。例: `dungeon_a`)。Tiledで開いて地名を書き、描いて、ほかのマップとドアでつなぐ。くわしくはマップ作りガイドの「ふだんの作業」。
