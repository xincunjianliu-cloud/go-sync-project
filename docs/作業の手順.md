# 作業の手順

## いつもの流れ

1. **GitHub Desktop で「Pull origin」**(ほかのPCの変更を受け取る)
2. 作業する
3. **GitHub Desktop で一言書いて「Commit to main」→「Push origin」**(ほかのPCに送る。Web版も自動で公開される)

---

## スプレッドシートを直したとき

作業フォルダの中のファイルを**ダブルクリック**するだけ。

| 直したもの | ダブルクリックするファイル |
|---|---|
| 会話(シナリオ) | `シナリオを取り込む.bat` |
| 強さ(ステータス) | `ステータスを取り込む.bat` |

- 最後に **`==== OK ====`** と出たら、いつもの流れの3(Commit → Push)をする
- **`==== FAILED ====`** と出たら、その少し上に理由が出ている。スプレッドシートを直して、もう一度ダブルクリック

---

## ゲームを試す

Tiledでマップを開いて **F5**。

---

## 困ったとき

- **Push したら「失敗しました」というメールが来た** → メールのリンクを開き、赤い×の行に理由が出ている。直してもう一度 Push
- **取り込みをなかったことにしたい** → GitHub Desktop で、変わったファイルを右クリック →「Discard changes」(Commit する前なら元に戻る)

---

## おまけ:敵の技(Skills列)の書き方

ステータスのスプレッドシートの、敵とボスのシートにある **Skills 列**(17列目)に技の名前を書く。2つ以上はカンマでつなぐ(例: `flame_burst,crushing_blow`)。全部空のままだと、取り込みは止まる(技が消えないように)。
