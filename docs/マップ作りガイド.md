# マップ作りガイド

このゲームのマップは **Tiled** で作ります。
上から順番に読めば、マップを1枚作れるようにしてあります。

---

## はじめに(PCごとに1回だけ)

1. Tiled を起動する(版は **1.12 以上**。「ヘルプ」→「Tiledについて」で確かめられる)
2. 上のメニューの「**プロジェクト**」→「**Open Project...**」(英語のまま出る)
3. 作業フォルダの中の `rpg.tiled-project` を選ぶ
4. 左に「プロジェクト」パネルが出れば成功
   - 出ないときは「表示」→「ビューとツールバー」→「プロジェクト」にチェック

次からは、Tiled を起動すると自動で開きます。

> **作業フォルダ**:このPCでは `rpg`、ほかのPCでは GitHub Desktop で作った `go-sync-project` フォルダ。

### ターミナルの開き方

コマンド(`go run ...`)は、Windows の **ターミナル**(PowerShell)に打ちます。

1. エクスプローラーで**作業フォルダ**を開く
2. 何もない所を右クリック →「**ターミナルで開く**」
   - 出ないときは、上の場所が書いてある欄をクリック → `powershell` と打って Enter
3. 出てきた画面にコマンドを貼り付け(右クリック)て、Enter
4. 次の行に `PS C:\...>` が出たら終わり

作業フォルダ以外で開くと、「作業フォルダで実行してください」と出て止まります。

# ふだんの作業

## 1. 新しいマップを作る

作業フォルダでターミナルを開いて(「はじめに」の最後を見る)、次を打ちます(`dungeon_a` は好きな名前に変える)。

```
go run ./tools/newmap dungeon_a
```

`assets\maps\dungeon_a.tmj` ができます。

- **名前**は英小文字で始めて、英小文字・数字・`_` だけにする(例: `dungeon_a`、`forest_2`)
- **名前は、公開した後は変えない**(セーブデータに残るため)
- **大きさ**は最初は 120×40 マス。変えたいときは後ろに横と縦のマス数を付ける(例: `go run ./tools/newmap dungeon_a 60 40`)。あとからでも変えられる(「たまに使う」の章)

できたら、Tiled の左の「プロジェクト」パネルから `dungeon_a.tmj` をダブルクリックして開きます。一覧に出ないときは、パネルの上で右クリック →「フォルダーを更新」。

### 地名・曲などを決める

「**マップ**」→「**マップのプロパティ...**」を開くと、左に欄が出ます。

| 欄 | 意味 | 空のままだと |
|---|---|---|
| 地名 | ドアで入ったときに左上に出る名前。セーブ画面にも出る | ファイル名が出る |
| 曲 | このマップで流れる曲(一覧から選ぶ) | フィールド1 |
| 戦闘背景 | このマップで戦うときの背景(一覧から選ぶ) | いつもの背景 |
| 入ると全回復 | チェックすると、入るたびに全回復する | 回復しない |

---

## 2. 描く

1. 右下の「**レイヤー**」パネルで、描くレイヤーを選ぶ
2. 右下の「**タイルセット**」パネルでタイルを選んで、マップに描く

新しいマップには、最初から次のレイヤーがあります。

| レイヤー | 何に使う |
|---|---|
| 床 | 床・地面 |
| `kabe` | 壁。**ここに描いたタイルは通れない** |
| `events` | しかけを置く(3章)。絵は描かない |
| `player` | 何も置かない。主人公はこの高さに描かれる |
| 主人公より上 | 主人公の上にかぶさるもの(天井の端・木の上など) |
| `collision` | 四角を置くと、そこが**通れない**(水など。絵は要らない) |

- 見た目だけのレイヤーは、**自由に増やしたり名前を変えたりしてよい**(影・小物など)
- `kabe`・`events`・`player`・`collision` の**4つは名前を変えない**
- Tiled で**非表示**(目のアイコン)にしたレイヤーは、ゲームでも見えない。`kabe` を非表示にすると「見えない壁」になる
- レイヤーの**不透明度**はゲームでもそのまま使われる
- レイヤーを**グループ(フォルダ)**にまとめてもよい

---

## 3. しかけを置く

宝箱・レバー・会話などは、こうやって置きます。

1. 「レイヤー」パネルで **`events`** を選ぶ
2. 上のツールバーの「**四角形を追加**」で、置きたい場所に四角を描く
3. 左のプロパティの「**クラス(Class)**」で、しかけの種類を一覧から選ぶ
4. 下に出てきた欄を埋める(アイテム・敵・曲などは一覧から選ぶ)

### しかけの種類

| 種類(クラス) | 何ができるか | 埋める欄 |
|---|---|---|
| **宝箱** | 開けるとアイテムが手に入る | 中身 |
| **会話** | 話しかける・調べるとセリフが出る | セリフ か 会話データ、2回目からのセリフ |
| **イベント** | 通り抜けるとセリフやボス戦が起きる | セリフ か 会話データ、ボス戦、歩く道順、すぐ始める |
| **ドア** | 触れると別のマップへ移動する(4章) | 行き先マップ、着地点、倒すまで通れないボス |
| **着地点** | ドアで来たときに立つ場所(4章) | プロパティの「名前(Name)」欄に名前、向き |
| **敵が出る場所** | この中を歩くと敵に出会う | 出る敵(複数選べる)、一度に出る最大数 |
| **ボス** | フィールドに立つボス。倒すと消える | ボス番号 |
| **レバー** | 上げ下げできる | レバーの名前、一度きり |
| **レバーの壁** | レバーを上げると開いて通れる | つながるレバーの名前、見た目だけ |
| **暗い場所** | 暗くなる。レバーを上げると明るくなる | 明るくするレバーの名前 |
| **鍵の宝箱** | 鍵が手に入る | 鍵の名前 |
| **鍵の壁** | 鍵がそろうと開く | 必要な鍵(2つ以上はカンマでつなぐ) |
| **ブロック** | 押して動かせる | ブロックの名前 |
| **ブロック置き場** | ブロックを乗せる場所 | 置き場の名前 |
| **ブロック扉** | 全部の置き場にブロックが乗ると開く | 置き場の名前(2つ以上はカンマでつなぐ) |

### 書き方のコツ

- **セリフ**:**半角**の `|` で区切ると、そこでページが変わる(日本語入力をオフにして Shift + ¥ キー。全角の `｜` では分かれない)。セリフも会話データも空だと「調べるとなにかあるかもしれない」と出る
- **会話データ**:スプレッドシートに書いた会話を一覧から選ぶ。選ぶとセリフの欄より優先される。新しい会話が一覧に出ないときは、`go run ./tools/update` を打ってから Tiled を開き直す
- **名前でつながるもの**(レバーとレバーの壁、鍵の宝箱と鍵の壁、ブロック置き場とブロック扉):**1文字も違わず同じ名前**にする
- **見た目だけ**(レバーの壁):チェックすると、レバーを上げても通れないまま、見た目だけが変わる
- **歩く道順**(イベント):`up`・`down`・`left`・`right` と距離(ピクセル。1マス=32)をカンマでつなぐ(例: `up128,right64`)
- **目的地**(会話・イベント・ボスの欄):画面に「次はここ」と出す機能。名前は全マップで重ならないようにし、順番は小さい数ほど先。ふつうは一度話しかける(通る)と達成。会話の「達成するボス」を選ぶと、そのボスを倒すまで達成にならない
- 宝箱・ブロック・レバーの壁などは、一度公開したら**消して作り直さない**(セーブの記録がずれることがある)。動かすのはよい

---

## 4. ほかのマップとドアでつなぐ

**どのマップも、ドアでつながっていないと公開できません。** 必ず行き帰りを作ります。

例:`school_1` と `dungeon_a` を行き来できるようにする

**行き(school_1 → dungeon_a)**
1. `dungeon_a` の `events` に四角を描き、クラス「**着地点**」、プロパティの「名前(Name)」欄に `入口`
2. `school_1` のドアにしたい場所の `events` に四角を描き、クラス「**ドア**」
   - 行き先マップ:`dungeon_a.tmj`
   - 着地点:`入口`

**帰り(dungeon_a → school_1)**
3. `school_1` の `events` に、クラス「着地点」・名前 `地下から` の四角
4. `dungeon_a` に、クラス「ドア」・行き先マップ `school_1.tmj`・着地点 `地下から` の四角

---

## 5. 試し遊び(F5)

**Ctrl+S** で保存して、**F5** を押すと、**今開いているマップから**ゲームが始まります。

- 立つ場所は着地点 `start_point`(新しいマップには最初からある。ドラッグで動かせる)
- 最初の1回は 10〜30秒(新しく準備したPCは 1〜2分)かかる。2回目からは速い
- F5 で何も起きないときは、上のツールバーの「コマンド」ボタン横の ▼ →「このマップで遊ぶ」

---

## 6. 送る

GitHub Desktop で送ります。やり方は `docs\作業の手順.md` を見てください。

- **同じマップを2台以上で同時に直さない**(違うマップならよい)
- 2台で同じマップを直してしまうと、Pull のときに「conflict(ぶつかり)」と出る。マップは混ぜられないので、どちらを残すか決めて、残さない方は直し直す(困ったら Claude に聞く)

---

## 7. チェックで止まったとき

Push すると、GitHub がマップのまちがいを自動で調べます。まちがいがあると Web版は公開されず、GitHub に登録したメールアドレスに「**失敗しました**」というメールが届きます。

1. メールのリンクを開き、赤い × の所を見ると、何がまちがっているか日本語で書いてある(例:「会話データ "chapter9" がありません」)
2. Tiled で直して保存
3. もう一度 Commit → Push

分からないときは、その画面を Claude に見せてください。
チェックの中身は全部覚えなくて大丈夫です。まちがえたら教えてくれます。

# たまに使う

## マップの大きさを変える

1. 「**マップ**」→「**マップのサイズを変更...**」
2. 幅・高さ(マス数)を入れる
3. 左や上に広げるときは、プレビューの中の絵をドラッグして位置を決める(しかけも一緒に動く)
4. OK → 保存

- 狭くすると、外にはみ出たタイルは消える。しかけがはみ出ていないか確かめる
- 公開済みのマップを左や上に広げると、そのマップでセーブしたときの立ち位置がずれることがある

## 水と机の橋の作り方

| 作りたいもの | 作り方 |
|---|---|
| ただの水(ずっと通れない) | 水を描いて、`collision` に四角を置いて囲む |
| 机の橋(レバーで渡れる) | 「レバーの壁」を置く + 机をレイヤーに描き、そのレイヤーのクラスを「**レバーで出るレイヤー**」にする |
| レバーで見た目が変わる水 | 「レバーの壁」で「見た目だけ」にチェック + 変わった後の水を「レバーで出るレイヤー」に描く |

- 「レバーで出るレイヤー」に描いた絵は、レバーを上げたときだけ出る(Tiled で非表示にしていても大丈夫)
- 橋の場所を `collision` の四角や `kabe` のタイルでふさがない(レバーを上げても渡れなくなる)

## 新しいタイル画像を足す

1. **画像を置く**:PNG を `assets\images\tiles` にコピー(名前は英小文字。例: `forest.png`)
2. **タイルセットを作る**:Tiled で「ファイル」→「新規」→「新しいタイルセット...」
   - 名前:`forest`
   - 種類:「**均等にタイルが並んだ画像を使用**」
   - 「マップに埋め込み」:**チェックを外す**
   - 画像:1 の PNG
   - タイルの幅・高さ:**32**
   - 保存先:`assets\tilesets`(`forest.tsx` ができる)
3. **マップで使う**:マップを開いて「マップ」→「**タイルセットを読み込み...**」→ `forest.tsx`

必要なら:
- **どこに置いても通れないタイル**にする:`forest.tsx` でタイルを選び、プロパティの「+」→ 名前 `wall`・種類 bool → チェック
- **動くタイル**にする:次の「動くタイル(アニメーション)を作る」を見る

### タイル画像に描き足すとき

- **横幅は変えない**。足すときは下に行を足す(横幅が変わると、全部のマップの絵がずれる)
- **同じファイル名のまま上書き保存**する(`forest (2).png` のような別名にしない)
- 描き足したら、Tiled でその `.tsx` を開いて保存し直す

## 動くタイル(アニメーション)を作る

水面のゆらぎ・たいまつの火・点滅するライトなど、**ずっと動き続けるタイル**を作れます。
タイル画像に動きのコマを並べて描いておき、「このタイルはこのコマを順番に見せる」と Tiled で設定します。

例:たいまつの火を3コマで動かす

1. **コマを描く**
   - タイル画像(例: `school.png`)に、火の絵を3コマ並べて描く
   - 空いている所がなければ、横幅は変えずに下に行を足して描く(上の「タイル画像に描き足すとき」)
2. **アニメーションを付ける**(Tiled)
   1. `assets\tilesets` の `.tsx`(例: `school.tsx`)を開く
   2. 1コマ目のタイルをクリック
   3. 「**タイル・アニメーション エディター**」(フィルムのアイコン)を開く
   4. 右のタイル一覧から、1コマ目 → 2コマ目 → 3コマ目 の順に、左の欄へドラッグして並べる
   5. 各コマの数字を決める。そのコマを見せる長さ(ミリ秒。`200` なら0.2秒)
   6. エディターを閉じて、`.tsx` を保存
3. **マップに置く**:マップで **1コマ目のタイル**を描く(Tiled の画面でも動いて見える)
4. **F5** で確かめる

### 決まり

- コマに使えるのは、**同じタイルセットの中のタイル**だけ
- コマの長さは **1 以上**(0 にするとチェックで止まる)
- 動きはタイルセットに付くので、**そのタイルを置いた全部のマップ**で同じように動く
- マップに置くのは1コマ目だけ。2コマ目以降を直接置くと、そこは動かない絵になる

---

## やってはいけないこと

- 公開した後にマップのファイル名を変える
- タイル画像の横幅を変える
- 水など広く敷くタイルに `wall` を付ける(床の上まで通れなくなる)。水は `collision` の四角で囲む
- Tiled の「Custom Types Editor」(カスタムタイプの編集画面)でクラスや一覧を書き換える(ゲームのデータから自動で作っている。直すときは `go run ./tools/update`)
- 次の Tiled の機能は、ゲームでは使えない。絵はタイルレイヤーに描き、しかけは `events` に四角で置く
  - 無限マップ、テンプレート、「タイルを挿入」で置くオブジェクト、画像レイヤー
  - レイヤーのずらし・視差・色合い、オブジェクトの回転、`collision` の楕円、タイルの当たり判定エディタ
