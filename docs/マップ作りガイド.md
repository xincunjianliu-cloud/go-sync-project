# マップ作りガイド

このゲームのマップは **Tiled** で作ります。
上から順番に読めば、マップを1枚作れるようにしてあります。

---

## はじめに(PCごとに1回だけ)

1. Tiled を起動する(版は **1.12 以上**。「ヘルプ」→「Tiledについて」で確かめられる)
2. 上のメニューの「**プロジェクト**」→「**Open Project...**」(英語のまま出る)
3. 作業フォルダの中の `rpg.tiled-project` を選ぶ
4. 左に「プロジェクト」パネルが出れば成功
   - 出ないときは「表示」→「ビューとツールバー」→「プロジェクト」にチェック

次からは、Tiled を起動すると自動で開きます。

> **作業フォルダ**:このPCでは `rpg`、ほかのPCでは GitHub Desktop で作った `go-sync-project` フォルダ。

### ターミナルの開き方

コマンド(`go run ...`)は、Windows の **ターミナル**(PowerShell)に打ちます。

1. エクスプローラーで**作業フォルダ**を開く
2. 何もない所を右クリック →「**ターミナルで開く**」
   - 出ないときは、上の場所が書いてある欄をクリック → `powershell` と打って Enter
3. 出てきた画面にコマンドを貼り付け(右クリック)て、Enter
4. 次の行に `PS C:\...>` が出たら終わり

作業フォルダ以外で開くと、「作業フォルダで実行してください」と出て止まります。

# ふだんの作業

## 1. 新しいマップを作る

作業フォルダでターミナルを開いて(「はじめに」の最後を見る)、次を打ちます(`dungeon_a` は好きな名前に変える)。

```
go run ./tools/newmap dungeon_a
```

`assets\maps\dungeon_a.tmj` ができます。

- **名前**は英小文字で始めて、英小文字・数字・`_` だけにする(例: `dungeon_a`、`forest_2`)
- **名前は、公開した後は変えない**(セーブデータに残るため)
- **大きさ**は最初は 120×40 マス。変えたいときは後ろに横と縦のマス数を付ける(例: `go run ./tools/newmap dungeon_a 60 40`)。あとからでも変えられる(「たまに使う」の章)

できたら、Tiled の左の「プロジェクト」パネルから `dungeon_a.tmj` をダブルクリックして開きます。一覧に出ないときは、パネルの上で右クリック →「フォルダーを更新」。

### 地名・曲などを決める

「**マップ**」→「**マップのプロパティ...**」を開くと、左に欄が出ます。

| 欄 | 意味 | 空のままだと |
|---|---|---|
| 地名 | ドアで入ったときに左上に出る名前。セーブ画面にも出る | ファイル名が出る |
| 曲 | このマップで流れる曲(一覧から選ぶ) | フィールド1 |
| 戦闘背景 | このマップで戦うときの背景(一覧から選ぶ) | いつもの背景 |
| 入ると全回復 | チェックすると、入るたびに全回復する | 回復しない |

---

## 2. 描く

1. 右下の「**レイヤー**」パネルで、描くレイヤーを選ぶ
2. 右下の「**タイルセット**」パネルでタイルを選んで、マップに描く

新しいマップには、最初から次のレイヤーがあります(下から順)。

| レイヤー | クラス | 何に使う |
|---|---|---|
| 床 | (なし) | 床・地面 |
| 壁 | 通れないレイヤー | 壁。**描いたタイルは通れない** |
| しかけ | しかけレイヤー | 宝箱・ドアなどのしかけを置く(3章)。絵は描かない |
| 主人公の高さ | 主人公の高さ | 何も置かない。主人公はこの重なり順で描かれる |
| 主人公より上 | (なし) | 主人公の上にかぶさるもの(天井の端・木の上など) |
| 通れない四角 | 通れないレイヤー | 四角を置くと、そこが**通れない**(水など。絵は要らない) |

### レイヤーの働きは「クラス」で決める

レイヤーの働きは、**名前ではなくクラス**で決まります。**名前は全部自由**です。

1. レイヤーパネルでレイヤーを選ぶ
2. 左のプロパティの「**クラス(Class)**」で選ぶ

| クラス | 働き |
|---|---|
| **通れないレイヤー** | タイルレイヤーなら描いたタイルが、オブジェクトレイヤーなら置いた四角が**通れない**。何枚あってもよい |
| **レバーで出るレイヤー** | 描いた絵が、**レバーを上げたときだけ**出る(机の橋など) |
| **しかけレイヤー** | 宝箱・ドアなどの**しかけ**を置く。何枚あってもよい |
| **主人公の高さ** | 主人公を描く重なり順の位置。**1マップに1枚だけ**。何も置かない |
| (なし) | 見た目だけ |

- クラスを選び忘れると働かない(壁の絵があっても通れる、しかけが動かない)。F5 で確かめる
- 間違えても、チェックが「クラスを○○にしてください」と教えてくれる

### レイヤーの名前

名前は自由ですが、次を守ります。

- **何が描いてあるか分かる名前**にする(例: `床`、`影`、`建物の壁`、`水の当たり`)。`タイルレイヤー1` のままにしない
- **同じ名前を2つ作らない**(2つ目は `影2` のように番号を付ける)
- 中身が空になったレイヤーは**消す**
- 確かめるためだけに置いて非表示にしたレイヤーは、`机(確認用・非表示)` のように分かる名前にする
- 日本語でよい

### 重なり順

レイヤーパネルで「**主人公の高さ**」より**下**にあるレイヤーは主人公の下に、**上**にあるレイヤーは主人公の上にかぶさって描かれます(木の上・天井の端は「主人公の高さ」より上へ)。

### そのほか

- Tiled で**非表示**(目のアイコン)にしたレイヤーは、ゲームでも見えない。通れないレイヤーを非表示にすると「見えない壁」になる
- レイヤーの**不透明度**はゲームでもそのまま使われる
- レイヤーを**グループ(フォルダ)**にまとめてもよい
- もう描き直さないレイヤー(床など)は、レイヤーパネルの**鍵のアイコン**でロックしておくと、間違えて描くのを防げる(ゲームには影響しない)

---

## 3. しかけを置く

宝箱・レバー・会話などは、こうやって置きます。

1. 「レイヤー」パネルで、クラスが**しかけレイヤー**のレイヤー(新しいマップでは「しかけ」)を選ぶ
2. 上のツールバーの「**四角形を追加**」で、置きたい場所に四角を描く
3. 左のプロパティの「**クラス(Class)**」で、しかけの種類を一覧から選ぶ
4. 下に出てきた欄を埋める(アイテム・敵・曲などは一覧から選ぶ)

### しかけの種類

| 種類(クラス) | 何ができるか | 埋める欄 |
|---|---|---|
| **宝箱** | 開けるとアイテムが手に入る | 中身 |
| **会話** | 話しかける・調べるとセリフが出る | セリフ か 会話データ、2回目からのセリフ |
| **イベント** | 通り抜けるとセリフやボス戦が起きる | セリフ か 会話データ、ボス戦、歩く道順 |
| **ドア** | 触れると別のマップへ移動する(4章) | 行き先マップ、着地点、倒すまで通れないボス |
| **着地点** | ドアで来たときに立つ場所(4章) | プロパティの「名前(Name)」欄に名前、向き |
| **敵が出る場所** | この中を歩くと敵に出会う | 出る敵(複数選べる)、一度に出る最大数 |
| **ボス** | フィールドに立つボス。倒すと消える | ボス番号 |
| **レバー** | 上げ下げできる | レバーの名前、一度きり |
| **レバーの壁** | レバーを上げると開いて通れる。**開いたときの絵は「レバーで出るレイヤー」に描く** | つながるレバーの名前、見た目だけ |
| **暗い場所** | 暗くなる。レバーを上げると明るくなる | 明るくするレバーの名前 |
| **鍵の宝箱** | 鍵が手に入る | 鍵の名前 |
| **鍵の壁** | 鍵がそろうと開く | 必要な鍵(2つ以上はカンマでつなぐ) |
| **ブロック** | 押して動かせる | ブロックの名前 |
| **ブロック置き場** | ブロックを乗せる場所 | 置き場の名前 |
| **ブロック扉** | 全部の置き場にブロックが乗ると開く | 置き場の名前(2つ以上はカンマでつなぐ) |

### 書き方のコツ

- **セリフ**:**半角**の `|` で区切ると、そこでページが変わる(日本語入力をオフにして Shift + ¥ キー。全角の `｜` では分かれない)。セリフも会話データも空だと「調べるとなにかあるかもしれない」と出る
- **会話データ**:スプレッドシートに書いた会話を一覧から選ぶ。選ぶとセリフの欄より優先される。新しい会話が一覧に出ないときは、`go run ./tools/update` を打ってから Tiled を開き直す
- **名前でつながるもの**(レバーとレバーの壁、鍵の宝箱と鍵の壁、ブロック置き場とブロック扉):**1文字も違わず同じ名前**にする
- **見た目だけ**(レバーの壁):チェックすると、レバーを上げても通れないまま、見た目だけが変わる。どちらの場合も、開いたときの絵を「レバーで出るレイヤー」に描く(描き忘れるとチェックで止まる)
- **歩く道順**(イベント):通ったとき、主人公がこの道順を**勝手に歩いてから**セリフやボス戦が始まる。`up`・`down`・`left`・`right` と距離(ピクセル。1マス=32)をカンマでつなぐ(例: `up128,right64`)。空ならすぐ始まる
- **目的地**(会話・イベント・ボスの欄):メニューの**ミニマップ**に「次に行く場所」の印を出す機能。別のマップにあるときは、そこへ向かうドアに印が出る
  - **目的地の名前**:目的地にしたいしかけに付ける名前。全マップで重ならないようにする。空なら目的地にならない
  - **目的地の順番**:小さい数ほど先。達成すると、次の数の目的地に印が移る
  - **達成するボス**(会話だけ):ふつうは一度話しかける(イベントは通る、ボスは倒す)と達成。会話でボスを選ぶと、話しかけるだけでは達成にならず、**そのボスを倒したとき**に達成になる
- 宝箱・ブロック・レバーの壁などは、一度公開したら**消して作り直さない**(セーブの記録がずれることがある)。動かすのはよい

---

## 4. ほかのマップとドアでつなぐ

**どのマップも、ドアでつながっていないと公開できません。** 必ず行き帰りを作ります。

例:`school_1` と `dungeon_a` を行き来できるようにする

**行き(school_1 → dungeon_a)**
1. `dungeon_a` のしかけレイヤーに四角を描き、クラス「**着地点**」、プロパティの「名前(Name)」欄に `入口`
2. `school_1` のドアにしたい場所に、しかけレイヤーで四角を描き、クラス「**ドア**」
   - 行き先マップ:`dungeon_a.tmj`
   - 着地点:`入口`

**帰り(dungeon_a → school_1)**
3. `school_1` のしかけレイヤーに、クラス「着地点」・名前 `地下から` の四角
4. `dungeon_a` に、クラス「ドア」・行き先マップ `school_1.tmj`・着地点 `地下から` の四角

---

## 5. 試し遊び(F5)

**Ctrl+S** で保存して、**F5** を押すと、**今開いているマップから**ゲームが始まります。

| キー | 敵 | 使うとき |
|---|---|---|
| **F5** | 歩いていて**出会わない** | ふだんの確かめ(見た目・しかけ・ドア) |
| **Shift+F5** | 出会う | 「敵が出る場所」の出方を確かめる |

- ボスやイベントの戦闘は、F5 でも起きる
- 立つ場所は着地点 `start_point`(新しいマップには最初からある。ドラッグで動かせる)
- 最初の1回は 10〜30秒(新しく準備したPCは 1〜2分)かかる。2回目からは速い
- F5 で何も起きないときは、上のツールバーの「コマンド」ボタン横の ▼ →「このマップで遊ぶ(敵なし)」
- キーが効かないときは、Tiled を一度閉じて開き直す(コマンドの設定を読み直す)

---

## 6. 送る

GitHub Desktop で送ります。やり方は `docs\作業の手順.md` を見てください。

- **同じマップを2台以上で同時に直さない**(違うマップならよい)
- 2台で同じマップを直してしまうと、Pull のときに「conflict(ぶつかり)」と出る。マップは混ぜられないので、どちらを残すか決めて、残さない方は直し直す(困ったら Claude に聞く)

---

## 7. チェックで止まったとき

Push すると、GitHub がマップのまちがいを自動で調べます。まちがいがあると Web版は公開されず、GitHub に登録したメールアドレスに「**失敗しました**」というメールが届きます。

1. メールのリンクを開き、赤い × の所を見ると、何がまちがっているか日本語で書いてある(例:「会話データ "chapter9" がありません」)
2. Tiled で直して保存
3. もう一度 Commit → Push

分からないときは、その画面を Claude に見せてください。
チェックの中身は全部覚えなくて大丈夫です。まちがえたら教えてくれます。

# たまに使う

## マップの大きさを変える

1. 「**マップ**」→「**マップのサイズを変更...**」
2. 幅・高さ(マス数)を入れる
3. 左や上に広げるときは、プレビューの中の絵をドラッグして位置を決める(しかけも一緒に動く)
4. OK → 保存

- 狭くすると、外にはみ出たタイルは消える。しかけがはみ出ていないか確かめる
- 公開済みのマップを左や上に広げると、そのマップでセーブしたときの立ち位置がずれることがある

## 水と机の橋の作り方

| 作りたいもの | 作り方 |
|---|---|
| ただの水(ずっと通れない) | 水を描いて、「通れない四角」(クラスが通れないレイヤーのオブジェクトレイヤー)に四角を置いて囲む |
| 机の橋(レバーで渡れる) | 「レバーの壁」を置く + 机をレイヤーに描き、そのレイヤーのクラスを「**レバーで出るレイヤー**」にする |
| レバーで見た目が変わる水 | 「レバーの壁」で「見た目だけ」にチェック + 変わった後の水を「レバーで出るレイヤー」に描く |

- 「レバーで出るレイヤー」に描いた絵は、レバーを上げたときだけ出る(Tiled で非表示にしていても大丈夫)
- レバーの壁が開いたときの見た目は、**このレイヤーに描いた絵だけ**で決まる(用意された絵は無い)。壁の範囲の全部のマスに描く。描き忘れたマスがあるとチェックで止まる
- 橋の場所を、通れないレイヤーの四角やタイルでふさがない(レバーを上げても渡れなくなる。チェックで止まる)

## 新しいタイル画像を足す

1. **画像を置く**:PNG を `assets\images\tiles` にコピー(名前は英小文字。例: `forest.png`)
2. **タイルセットを作る**:Tiled で「ファイル」→「新規」→「新しいタイルセット...」
   - 名前:`forest`
   - 種類:「**均等にタイルが並んだ画像を使用**」
   - 「マップに埋め込み」:**チェックを外す**
   - 画像:1 の PNG
   - タイルの幅・高さ:**32**
   - 保存先:`assets\tilesets`(`forest.tsx` ができる)
3. **マップで使う**:マップを開いて「マップ」→「**タイルセットを読み込み...**」→ `forest.tsx`

必要なら:
- **どこに置いても通れないタイル**にする:`forest.tsx` でタイルを選び、プロパティの「+」→ 名前 `wall`・種類 bool → チェック
- **動くタイル**にする:次の「動くタイル(アニメーション)を作る」を見る

### タイル画像に描き足すとき

- **横幅は変えない**。足すときは下に行を足す(横幅が変わると、全部のマップの絵がずれる)
- **同じファイル名のまま上書き保存**する(`forest (2).png` のような別名にしない)
- 描き足したら、Tiled でその `.tsx` を開いて保存し直す

## 動くタイル(アニメーション)を作る

水面のゆらぎ・たいまつの火・点滅するライトなど、**ずっと動き続けるタイル**を作れます。
タイル画像に動きのコマを並べて描いておき、「このタイルはこのコマを順番に見せる」と Tiled で設定します。

例:たいまつの火を3コマで動かす

1. **コマを描く**
   - タイル画像(例: `school.png`)に、火の絵を3コマ並べて描く
   - 空いている所がなければ、横幅は変えずに下に行を足して描く(上の「タイル画像に描き足すとき」)
2. **アニメーションを付ける**(Tiled)
   1. 左の「プロジェクト」パネルで、`assets/tilesets` の `.tsx`(例: `school.tsx`)をダブルクリック。タイルが一覧で並ぶ
   2. 一覧で **1コマ目のタイル**をクリック
   3. 上のツールバーの**フィルムのアイコン**(タイル・アニメーション エディター)を押す。小さな窓が開く
      - 窓の**左**:コマの並び(最初は空)
      - 窓の**右**:タイルの一覧
   4. 右の一覧から、1コマ目 → 2コマ目 → 3コマ目 の順に、左の欄へドラッグして並べる
   5. 左の各行の数字(最初は 100)をダブルクリックして、そのコマを見せる長さを入れる(ミリ秒。`200` なら0.2秒)
   6. 窓の下のプレビューで動きを確かめて、窓を閉じる
   7. **Ctrl+S** で `.tsx` を保存
3. **マップに置く**:マップで **1コマ目のタイル**を描く(Tiled の画面でも動いて見える)
4. **F5** で確かめる

### 縦2マス(以上)の物を動かす

1つのアニメーションは**1マス分**だけです。縦2マスの物(背の高いたいまつなど)は、**上のマスと下のマスに別々にアニメーションを付けます**。

例:縦2マスのたいまつを3コマで動かす

```
タイル画像に描いておく形
       コマ1  コマ2  コマ3
上の段  上1    上2    上3
下の段  下1    下2    下3
```

1. **上1** をクリック → フィルムのアイコン → **上1 → 上2 → 上3** をドラッグ → 長さを入れる(例: 3つとも `200`)→ 閉じる
2. **下1** をクリック → フィルムのアイコン → **下1 → 下2 → 下3** をドラッグ → 長さを**上とまったく同じ**にする → 閉じる
3. **Ctrl+S** で `.tsx` を保存
4. マップに **上1** を描き、そのすぐ下に **下1** を描く

- コマの数と長さが同じなら、上と下は**いつもそろって動く**(ゲームはマップ全体で1つの時計を使っている)
- 長さを直すときは、**上と下の両方**を直す。片方だけ変えるとずれて見える
- 横2マスや、2×2マスの物も同じやり方(マスごとに付ける)

### アニメーションをやめる

1. `.tsx` を開いて、**1コマ目のタイル**をクリック
2. フィルムのアイコン(タイル・アニメーション エディター)を押す
3. 窓の左のコマを**全部**選んで(1つ目をクリック → Shift を押しながら最後をクリック)、**Delete** キー
4. 窓を閉じて、**Ctrl+S** で `.tsx` を保存

マップに置いてあるタイルは、そのまま**1コマ目の絵で止まった**状態になります(消えません)。縦2マスの物は、上と下の両方でやめます。

### うまくいかないとき

- **コマを並べ間違えた**:窓の左で、その行を選んで Delete キーで消して、並べ直す
- **動かない**:マップに描いたのが1コマ目か確かめる。2コマ目以降を直接描くと、そこは動かない絵になる
- **上と下がずれる**:両方の長さを見比べて、同じにそろえる

### 決まり

- コマに使えるのは、**同じタイルセットの中のタイル**だけ
- コマの長さは **1 以上**(0 にするとチェックで止まる)
- 動きはタイルセットに付くので、**そのタイルを置いた全部のマップ**で同じように動く

## やってはいけないこと

- 公開した後にマップのファイル名を変える
- タイル画像の横幅を変える
- 水など広く敷くタイルに `wall` を付ける(床の上まで通れなくなる)。水は「通れない四角」で囲む
- Tiled の「Custom Types Editor」(カスタムタイプの編集画面)でクラスや一覧を書き換える(ゲームのデータから自動で作っている。直すときは `go run ./tools/update`)
- 次の Tiled の機能は、ゲームでは使えない。絵はタイルレイヤーに描き、しかけはしかけレイヤーに四角で置く
  - 無限マップ、テンプレート、「タイルを挿入」で置くオブジェクト、画像レイヤー
  - レイヤーのずらし・視差・色合い、オブジェクトの回転、通れないレイヤーの楕円、タイルの当たり判定エディタ
